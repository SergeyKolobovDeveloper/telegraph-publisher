# Telegra.ph OOP Publisher (Affnetix Test )

Професійний об'єктно-орієнтований PHP-скрипт для автоматизованої публікації матеріалів на платформі **Telegra.ph** за допомогою нативного **cURL** та офіційного API.

##  Основний функціонал
- **Об'єктно-орієнтований підхід (OOP)**: чиста архітектура класу `TelegraphPublisher`.
- **Пряма взаємодія з API**: висока швидкість та надійність публікації матеріалів через ендпоінти Telegra.ph API.
- **Файлове кешування токена (`token.txt`)**: автоматичне збереження та повторне використання `access_token` для уникнення зайвих реєстрацій акаунтів.
- **Автоматичне логування (`result.csv`)**: фіксація всіх успішних публікацій у суворій відповідності до ТЗ у форматі `Title | Author | URL | Date`.
- **Безпека**: обробка помилок через винятки (`try-catch`) та налаштування cURL для локальних середовищ розробки (тестовано на MAMP).
